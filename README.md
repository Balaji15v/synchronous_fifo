This project provides a robust, parameterized implementation of a Synchronous FIFO (First-In, First-Out) buffer written in Verilog, designed to reliably manage data flow between modules operating within a single clock domain. By utilizing the industry-standard "extra MSB" pointer method, the design effectively eliminates the common ambiguity between "full" and "empty" states that occurs in simpler circular memory implementations. The module is fully configurable through parameters for depth and width, making it highly adaptable for various data-path requirements in FPGA or ASIC designs. The accompanying testbench ensures functional verification by stimulating the FIFO through a full write and read cycle, confirming that the status signals—full and empty—trigger accurately under all operational conditions.
